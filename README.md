## 📌 기본 전제 3원칙
1. **적격증빙 (5종):** 카드매출전표, (세금)계산서, 현금영수증, 3만원 이하의 간이영수증, 원천징수
2. **법인카드 우선:** 카드 사용 가능 시 법인카드 사용이 원칙. 부득이한 사유로 사용 불가한 경우 **개인카드도 사유서 작성 시 사용 가능**
3. **자체영수증 필수:** 어떠한 적격증빙도 받을 수 없는 상황이라면 반드시 **자체영수증(사내 양식)**이라도 수취/작성

## 📑 항목별 전표 증빙 기준 요약

### 1. 소품(물건) 구매
- **1-1. 일반 상점 구매:** 신용카드, 현금영수증(지출증빙)
- **1-2. 노점 등 증빙 불가처:** 자체 영수증 (3만원 이하는 무관하나, 3만원 초과 시 상세 내용 작성 필수)
- **1-3. 중고거래 (당근마켓 등):** 자체 영수증 (거래상대방의 기본 정보(이름, 휴대폰번호) 필수 기재)

### 2. 출연료
- **2-1. 연예인**
  - **2-1-1. 소속사:** 세금계산서
  - **2-1-2. 개인:** 신분증 사본 (사업소득 원천징수)
- **2-2. 일반인**
  - **2-2-1. 125,000원 이상:** 신분증 사본 필수 (기타소득 원천징수)
  - **2-2-2. 125,000원 미만:** 가능하면 신분증 사본, 불가능할 경우 기본 정보(이름, 휴대폰번호) 구비 (125,000원은 세법상 필수 원천징수 대상 아님)

### 3. 개인에게 지급하는 상품 (상금·기프티콘)
* *대회 유형(불특정다수 심야괴담회 등 vs 특정다수)에 따라 기타소득 필요경비 상이*
- **3-1. 물품:** 신분증 사본 (물품 가액만큼 기타소득 원천징수) / 구매 시 세금계산서, 카드, 현금영수증
- **3-2. 상금:** 신분증 사본 (기타소득 원천징수)
- **3-3. 기프티콘(상품권):** 신분증 사본 (물품 가액만큼 기타소득 원천징수) / 구매 시 세금계산서, 카드, 현금영수증
  - *부득이하게 신분증 정보를 받을 수 없는 경우: [접대비] 처리 (단, 수불부 관리를 위해 이름/휴대폰번호 필수 구비)*

### 4. 해외 출장 사용 건
- 가능하면 카드 결제 우선, 부득이할 경우 자체 영수증 소명

### 5. 용역거래
- **5-1. 개인:** 신분증 사본 (사업소득 또는 기타소득 원천징수)
- **5-2-1. 개인사업자:** (세금)계산서, 신분증 사본 *(면세사업자일 경우 계산서를 받더라도 사업소득 원천징수)*
- **5-2-2. 법인사업자:** (세금)계산서
- **5-3. 해외법인:** 인보이스 (Invoice)

### 6. 선물 (접대비)
- **필요 증빙:** 카드, 현금영수증, 세금계산서
- **사전 품의 의무:** 접대비의 경우 사내 위임전결규정에 따른 사전 품의 필수

## ⚡ 배포 후 모바일 캐싱 방지 시스템
본 프로젝트에는 모바일 브라우저(Safari, Chrome, 카톡 인앱브라우저)에서 예전 캐시된 화면이 계속 뜨는 현상을 방지하는 3단계 캐시 무효화 기술이 적용되어 있습니다:
1. **HTML No-Cache 메타태그:** 브라우저에게 캐시하지 않도록 지시
2. **Vercel Cache-Control 헤더 (`vercel.json`):** CDN 캐시 방지 (`max-age=0, must-revalidate`)
3. **실시간 버전 자동 감지 (`version.json`):** 제작진이 앱 화면을 켤 때마다 최신 규정을 체크하여 새 버전이 감지되면 상단에 **[새로고침] 알림 배너**가 자동으로 나타납니다.
