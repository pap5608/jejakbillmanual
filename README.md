## 📑 7대 핵심 전표 카테고리 구성 (세법 기준)

### 1. 소품(물건) 구매
- **1-1. 일반 상점 및 온라인몰:** 법인카드 매출전표 + 쿠팡/스마트스토어 주문상세(품목명세서) 필수 첨부
- **1-2. 전통시장 (현금 구매):** 법인세법상 3만원 초과 시 가산세 2%, 부득이한 노점 결제 시 [계좌이체증 + 판매자확인서 + 현장사진] 증빙
- **1-3. 중고거래 (당근마켓·번개장터):** 개인 간 거래로 적격증빙 불가 ➔ [이체확인증 + 판매글 캡처 + 채팅내역 + 물품사진] 4종 세트

### 2. 출연료 (소득세법 기준)
- **2-1. 연예인:** 소속사(기획사) 전자세금계산서 발행 vs 개인 자격 사업소득세 3.3% 원천징수
- **2-2. 일반인 (방청객·사연자·인터뷰):** 소득세법 제84조 과세최저한 적용 (지급액 125,000원 이하는 세금 0원 전액 지급, 초과 시 8.8% 원천징수)

### 3. 상품 / 상금 / 기프티콘
- **불특정 다수 공모전 (심야괴담회 사연 등):** 소득세법상 필요경비 80% 인정 (실효세율 4.4% 제세공과금 원천징수), 상금 25만원 이하 비과세
- **기프티콘/모바일 상품권:** 구매 영수증 외 [상품권 관리대장] 및 [수령인 연락처/발송내역] 증빙 필수

### 4. 해외 출장 사용 건
- **해외 법인카드:** 카드사 원화 청구금액 기준 정산
- **현지 현금 지출:** 환전 영수증 환율 적용, 현지 인보이스 뒷면 한글 용도/일시/참석자 수기 소명

### 5. 용역거래 (외주 스태프/기술용역)
- **개인 프리랜서:** 사업소득 3.3% 원천징수 + 용역계약서 + 신분증/통장
- **국내 사업자:** 전자세금계산서 + 사업자등록증 + 통장사본
- **해외 법인:** 해외 인보이스 + 계약서 + 외화송금확인서

### 6. 해외 영상사용료 (Footage/조세조약)
- **조세조약 제한세율 적용:** 미국, 일본 등 국가별 제한세율(10~15%) 적용
- **필수 서류:** 라이선스 계약서 + 인보이스 + **해외 거주자증명서 (Certificate of Residence)** 원본 + 비과세·면제신청서 (미제출 시 기본세율 22% 차감)

### 7. 선물 / 접대비 (업무추진비)
- **법인세법 적격증빙 강제:** 30,000원 초과 시 법인카드/세금계산서/현금영수증(지출증빙)만 인정 (개인카드 사용분 전액 손금불산입)
- **청탁금지법(김영란법) 한도:** 식사 5만원 / 일반선물 5만원 / 농축수산물 15만원 / 경조사비 5만원(화환 10만원)
