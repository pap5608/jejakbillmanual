## 📌 기본 전제 4대 원칙 (적격증빙 핵심 가이드)
1. **적격증빙의 종류:** 카드매출전표, (세금)계산서, 현금영수증, 원천징수 영수증 (3만원 이하일 경우 간이영수증도 가능)
2. **법인카드 우선 원칙:** 카드 사용 가능 시 법인카드 사용이 원칙. 부득이한 사유로 불가한 경우에 한해 **[사유서 작성] 시 개인카드 사용 가능 (개인 연말정산 시 카드 사용내역에서 제외 필요)** (`개인신용카드 사용 사유서.hwp` 웹 다운로드 제공)
3. **적격증빙 불가 시 자체영수증 필수:** 어떠한 적격증빙도 받을 수 없는 상황이라면 반드시 **자체영수증(사내 양식)**이라도 수취·작성
4. **현금영수증 사업자지출용 발급 필수:** 현금영수증 발급 시 반드시 **사업자지출용 (사업자번호 입력: 116-81-13833)**으로 발급

## 🗂️ 6대 전표 처리 대분류 요약

### 소품·물건 구매
- **일반 상점 구매:** 카드, 현금영수증 (부득이 개인카드 사용 시 사유서 서식 구비)
- **노점 등 증빙 불가처:** 자체 영수증 (3만원 이하면 무관하나 초과일 경우 상세한 내용 작성 필요), **가능할 경우 송금증**
- **중고거래 (개인 직거래):** **자체 영수증** (거래상대방 이름, 휴대폰번호 필수 기재), **송금증**, **거래내역 캡쳐**

### 출연료
- **연예인 소속사:** 세금계산서
- **연예인 개인:** 신분증 사본 (사업소득 원천징수)
- **일반인 (125,000원 이상):** 신분증 사본 (기타소득 원천징수)
- **일반인 (125,000원 미만):** 가능하면 신분증 사본 (기타소득 원천징수), 불가능할 경우 기본 정보(이름, 휴대폰번호) 구비 (125,000원은 세법상 필수 원천징수 대상이 아님)

### 개인에게 지급하는 상품
* **선행 시스템 통제 필수:** 경품 지급 시 이벤트 응모 약관에 **"경품 발송 및 제세공과금 처리를 위한 개인정보(주민등록번호) 수집 동의"**를 필수 항목으로 넣어야 하며, 인적사항 제공을 거부할 경우 당첨을 취소하는 시스템 통제가 선행되어야 함
- **물품:** 신분증 사본 (물품 가액만큼 기타소득 원천징수) / 물품 구매는 세금계산서, 카드 결제, 현금영수증
- **상금:** 신분증 사본 (기타소득 원천징수)
- **기프티콘(상품권):** 신분증 사본 (물품 가액만큼 기타소득 원천징수) / 구매는 세금계산서, 카드 결제, 현금영수증

### 해외 출장 사용 건
- 가능하면 카드, 부득이할 경우 자체 영수증

### 용역거래
- **개인:** 신분증 사본 (사업/기타소득 원천징수)
- **개인사업자:** (세금)계산서, 신분증 사본 *(면세사업자면서 인적용역, 병의원 용역을 제공할 경우 계산서를 발급 받더라도 사업소득 원천징수 함)*
- **법인사업자:** (세금)계산서
- **해외법인:** 인보이스 *(국내원천소득 여부 등 확인은 재무팀 검토 필요)*

### 선물 (접대비)
- **필요 증빙:** **법인카드 (개인카드 사용불가)**, 현금영수증, 세금계산서
- **수령자 기준:** **선물 품목, 수령자 정보(성명, 소속 등)** 필수 기재/관리
- **접대비 위임전결규정(공통.6.나.3) 사전 품의:**
  - 1건당 500만 원 이상 : **사장** 전결
  - 1건당 100만 ~ 500만 원 미만 : **부사장** 전결
  - 1건당 100만 원 미만 : **본부장** 전결
  - 1건당 20만 원 미만의 회사명의 경조사 관련 사항 : **팀장** 전결

## ⚡ 배포 후 모바일 캐싱 방지 시스템
본 프로젝트에는 모바일 브라우저(Safari, Chrome, 카톡 인앱브라우저)에서 예전 캐시된 화면이 계속 뜨는 현상을 방지하는 3단계 캐시 무효화 기술이 적용되어 있습니다:
1. **HTML No-Cache 메타태그:** 브라우저에게 캐시하지 않도록 지시
2. **Vercel Cache-Control 헤더 (`vercel.json`):** CDN 캐시 방지 (`max-age=0, must-revalidate`)
3. **실시간 버전 자동 감지 (`version.json`):** 제작진이 앱 화면을 켤 때마다 최신 규정을 체크하여 새 버전이 감지되면 상단에 **[새로고침] 알림 배너**가 자동으로 나타납니다.
